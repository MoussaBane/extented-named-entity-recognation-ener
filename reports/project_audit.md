# Project Audit

This document summarizes a full-code audit of the repository and the status of implemented components.

## Repository snapshot
- Root scripts: `scripts/train_ner.py`, `scripts/run_embedding_analysis.py`, `scripts/run_analysis.py`
- Analysis modules: `ner_stats/` (many utilities: cva, embeddings, evaluation, visualization, statistics, etc.)
- Data: `data/` (CoNLL splits and annotation folders)
- Notebooks: `notebooks/embedding_visualization.ipynb`
- Example outputs: `results_example/` and `results/` (generated by pipelines)

## Existing Components

- Annotation parsing: Status: COMPLETE
  - Why: `ner_stats/data_utils.py` and `ner_stats/conll_reader.py` provide CoNLL BIO readers and utilities. `data/annotation/` contains INCEpTION-style folders.

- Corpus statistics & QC (label counts, sentence/token stats, tagset checks): Status: COMPLETE
  - Why: `scripts/run_analysis.py` plus `ner_stats/statistics.py`, `ner_stats/tagset.py` implement corpus stats and QC. Example outputs found in `results_example/`.

- Visualization (plots, PCA, t-SNE, UMAP): Status: COMPLETE (PARTIAL for UMAP optional)
  - Why: `ner_stats/visualization.py` implements PCA, t-SNE, plotting helpers; `scripts/run_embedding_analysis.py` creates PCA/TSNE outputs. UMAP supported if optional dependency installed.

- Transformer embedding extraction: Status: COMPLETE
  - Why: `ner_stats/embeddings.py` and `ner_stats/embedding_analysis.py` provide `TransformerEmbedder`, token/word-aligned extraction and export (`export_embeddings`). `scripts/run_embedding_analysis.py` uses these.

- CVA (Common Vector Analysis) utilities: Status: COMPLETE
  - Why: `ner_stats/cva.py` implements class mean vectors, CVA common vectors, and cosine classifier utilities. `scripts/run_embedding_analysis.py` and `scripts/train_ner.py` build CVA class vectors.

- BERT training / token classification pipeline: Status: COMPLETE
  - Why: `scripts/train_ner.py` fine-tunes a Hugging Face `AutoModelForTokenClassification`, aligns labels and exposes CLI args for training/evaluation. Produces metrics and confusion matrices.

- Evaluation utilities (precision/recall/F1, confusion matrix plotting/saving): Status: COMPLETE
  - Why: `ner_stats/evaluation.py` computes token-level metrics and confusion matrix; `ner_stats/evaluation_report.py` serializes metrics, saves CSV/JSON and PNG confusion matrix.

- Embedding aggregation and class-vector building: Status: COMPLETE
  - Why: `ner_stats/embedding_analysis.py` supports aggregating embeddings per label and building prototypes or CVA vectors.

- Experiment logging: Status: PARTIAL
  - Why: `ner_stats/experiment_logger.py` exists and is used in `scripts/run_embedding_analysis.py`, but logging coverage is lightweight (simple event logs). No centralized experiment tracking system (MLflow, Sacred) integrated.

- Notebooks & example figures: Status: PARTIAL
  - Why: `notebooks/embedding_visualization.ipynb` exists and example figures in `results_example/` are present. Notebook may be exploratory and not fully parameterized for reproducible runs.

- Cross-validation (k-fold training/evaluation): Status: MISSING
  - Why: No scripts implement multi-fold cross validation. `scripts/train_ner.py` performs single train/eval split only.

- Per-fold metrics reporting: Status: MISSING
  - Why: No per-fold aggregation or saving of fold-level metrics is present.

- Alternative model baseline (CRF): Status: MISSING
  - Why: No CRF implementation or wrapper found. Only CVA and BERT exist.

- Top-K nearest label prediction / multi-nearest retrieval: Status: PARTIAL
  - Why: `ner_stats/cva.classify_embedding_by_cosine_similarity` returns only top-1 label. No top-3 retrieval utility present.

- OOV / unseen-entity experiment: Status: MISSING (PARTIAL support)
  - Why: Embedding extraction and class-vector lookup are implemented, enabling OOV experiments, but there is no dedicated procedure that constructs OOV set and runs the top-3 retrieval experiment.

- Context-only vs CVA+Context experiments / performance comparison: Status: MISSING (PARTIAL building blocks)
  - Why: `scripts/train_ner.py` measures BERT (supervised) vs CVA. But explicit experiments isolating "context-only" (embedding-only classifier) versus "CVA+context" combined classifier and their comparative performance/ablation are not implemented.

- PCA visualizations of entity embeddings with common vectors overlay: Status: PARTIAL
  - Why: `visualization.plot_prototypes_2d` exists to overlay prototypes, and `run_embedding_analysis.py` produces PCA; however automated overlay of CVA/mean prototypes is not included in default outputs.

- Thesis-ready tables and formatted figures: Status: PARTIAL
  - Why: Numeric outputs (CSV/JSON) and PNG figures are generated; however, thesis-ready LaTeX/markdown tables and consolidated figure generation (with captions, explained variance numbers) are not assembled automatically.

## Notes and immediate opportunities
- Reuseable building blocks for CVA, embedding extraction, evaluation, and visualization are present and well-structured.
- Missing pieces are primarily around experimental orchestration (k-fold CV, CRF baseline, OOV pipeline, top-K retrieval, and combined CVA+context experiments) and wrapping outputs into thesis-ready artifacts.
